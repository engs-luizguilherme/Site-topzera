# Universo Sertanejo

## Sobre o projeto
O Universo Sertanejo é um site criado para apresentar o sertanejo universitário e alguns artistas conhecidos desse estilo musical.

O site possui duas páginas: a página inicial e a página de artistas.

## Conceitos aplicados

- **Usabilidade:** o site possui menus e links simples para facilitar a navegação.
- **Experiência do usuário (UX):** foram utilizadas imagens e informações organizadas para deixar o site agradável.
- **Acessibilidade:** foram escolhidas cores que facilitam a leitura dos textos.
- **Responsividade:** o site se adapta a diferentes telas, como computadores e celulares.

## Escolhas de design

Foram utilizadas as cores vermelho, preto, branco e amarelo para combinar com o tema musical.

Também foram adicionadas fotos de artistas e cartões para organizar melhor as informações.

O menu permite navegar entre as duas páginas de forma simples.

## Tecnologias utilizadas

- HTML: estrutura do site.
- CSS: aparência, cores e organização.

## Arquivos

- `index.html`: página inicial.
- `artistas.html`: página dos artistas.
- `style.css`: estilos do site.
- `README.md`: documentação do projeto.

## Conclusão

O objetivo foi criar um site bonito, organizado e fácil de usar, aplicando os conceitos estudados em sala de aula.
